# Анимации версии 2 — спецификация для переноса

Документ для разработчика: что, как долго и с какой кривой движется в версии 2
(`v2.html`, `data-version="2.3"`, и `match.html`). Время везде в миллисекундах.

**Все сюжетные анимации написаны на anime.js v4** (`js/vendor/anime.umd.min.js`,
глобальный `anime`). Используются `anime.animate`, `anime.createTimeline` и
`anime.set`, поэтому код переносится в проект как есть: те же параметры, кривые
и таймлайны. На CSS остались только мгновенные отклики, то есть нажатия
`:active` и смена цвета (подробнее в разделе 13).

Рядом с каждым блоком указано, где лежит код. Версия 3 (`?app=3`) и старые
ветки 2.1 / 2.2 здесь не описаны.

## 1. Общий модуль `js/anim24.js` (глобальный `A24`)

Подключается сразу после anime.js. В нём лежат общие кривые и маленькие
помощники, поэтому код экранов короткий и везде одинаковый.

### Кривые — `A24.EASE`

| Имя | Значение (anime.js) | Где |
|---|---|---|
| `ios` — основная | `'cubicBezier(0.32, 0.72, 0.35, 1)'` | шторки, переходы, сворачивание карточек, нижняя навигация |
| `spring` — мягкая пружина | `'cubicBezier(0.34, 1.32, 0.42, 1)'` | индикаторы табов, «поп» элементов, тосты, тултип сундука, «Забрать» |
| `springStrong` — сильная пружина | `'cubicBezier(0.34, 1.56, 0.64, 1)'` | иконки, точки |
| `outExpo` | `'cubicBezier(0.22, 1, 0.36, 1)'` | искры, появление офферов, вылет наград подарка |
| `out` | `'cubicBezier(0, 0, 0.58, 1)'` | короткие пульсы, вспышки (= CSS `ease-out`) |
| `in` | `'cubicBezier(0.42, 0, 1, 1)'` | угасание, разгон (= CSS `ease-in`) |
| `inOut` | `'cubicBezier(0.42, 0, 0.58, 1)'` | бесконечные покачивания (= CSS `ease-in-out`) |
| `ease` | `'cubicBezier(0.25, 0.1, 0.25, 1)'` | фейды (= CSS `ease`) |

Кроме них встречаются встроенные кривые anime.js: `'out(3)'` (то же, что
easeOutCubic: счётчики, шкала), `'inOutQuad'`, `'inQuad'`, `'outQuad'`,
`'outElastic(1, 0.6)'`, `'linear'`.

### Помощники

| Функция | Что делает |
|---|---|
| `A24.play(targets, params, { keep })` | `anime.animate` и по окончании убирает инлайн-стили, которые поставила анимация, чтобы элемент снова слушался CSS (`:active`, классы). `keep: true` оставляет конечное состояние |
| `A24.clear(targets, params)` | убирает инлайн-значения анимированных свойств; для `x / y / scale / rotate…` убирает `transform` |
| `A24.pulse(el, scale = 1.2, duration = 300, ease = out)` | «пульс»: `keyframes: [{ scale }, { scale: 1 }]` |
| `A24.squash(el, 360)` | нажатие с отдачей: `scale 1 → 0.86 (33%) → 1.06 (66%) → 1`, `out` |
| `A24.popIn(el, peak = 1.5, 420, delay)` | «впрыгивание» бейджа: сначала `anime.set(scale 0)`, затем `0 → peak → 1`, `out` |
| `A24.reveal(el, cls, on, hidden, visible, duration = 250, ease = ease)` | показать или скрыть элемент, у которого видимое состояние задаёт CSS-класс `cls`. При показе класс ставится сразу и анимация идёт `hidden → visible`; при скрытии — наоборот, класс снимается в конце |
| `A24.loop(el, params)` | бесконечная анимация (`loop: true`). Сама отменяется, когда элемент убран со страницы. При «уменьшении движения» не запускается |
| `A24.arc(from, pop, ctrl, to, opts)` | ключевые кадры полёта «в цель» по дуге (см. раздел 2) |
| `A24.wait(ms)`, `A24.reduce` | пауза-Promise и флаг `prefers-reduced-motion` |

### Нажатие (press) — CSS

Все нажимаемые элементы при `:active` уменьшаются по кривой **ios**: кнопки и
плитки до `scale(0.97)`, карточки и иконки до `0.94–0.96`, стеклянные круглые
кнопки 44px до `0.9`. Длительность 150–180. Это `transition` в CSS: мгновенный
отклик на палец anime.js не нужен.

### Уменьшение движения

При `prefers-reduced-motion: reduce`:
- `A24.loop` не запускает бесконечные анимации (левитация, свечения, радар);
- длинные последовательности сокращаются: в поиске соперника паузы не дольше
  300, таймлайны сразу доигрываются через `tl.complete()`;
- в экране результата нет конфетти.

## 2. Общие компоненты

### Переход между разделами (нижняя навигация)
`js/v2.js` → `showScreen()`, `moveTabHighlight()`

- Разделы сменяются **кроссфейдом**: новый раздел `anime.animate(toEl, { opacity: 1, duration: 250, ease: ease })`,
  старый одновременно `opacity: 0`, 250, а в `onComplete` скрывается
  (`visibility: hidden`). Горизонтального сдвига нет: разделы будут на разных роутах.
- Подсветка активного таба: `anime.animate(highlight, { x, width, duration: 450, ease: spring })`,
  где `x = tab.offsetLeft − 4`, `width = tab.offsetWidth + 8`. Без анимации — `anime.set`.
  Для раздела без таба (профиль) подсветка гаснет: `opacity: 0`, 250.
- Иконка таба при нажатии: CSS `:active`, `scale(0.85)`, 200.

### Сегменты (вкладки внутри раздела: «Ежедневные / Каждую неделю»)
`js/v2.js` → `createChipTabs()`

- Индикатор перетекает: `anime.animate(indicator, { x, y, width, duration: 380, ease: spring })`.
- Новая панель проявляется: `A24.play(panel, { opacity: [0, 1], duration: 250, ease: out })`.
- Высота контейнера подстраивается: `anime.animate(content, { height: h, duration: 400, ease: ios })`.
  Только в момент переключения; изменения внутри панели (карточка свернулась)
  ставят высоту сразу.

### Шторки (bottom sheet)
`js/sheets.js` → `sheetShow()`, `sheetHide()`, `attachSheetSwipe()`, `bottomSheet()`

- Открытие: `A24.play(sheet, { y: [from, 0], duration, ease: ios })`, где
  `from = sheet.offsetHeight × 1.05` (сдвиг в пикселях, а не в %).
- Закрытие: `y: [from, offsetHeight × 1.05]`, затем снимается класс `is-open`.
- Затемнение: `opacity [0, 1]` / `[1, 0]`, кривая `ease`.
- Длительности: `.bs` — 450 (фон 350); старые `.v2-sheet` — 420 (фон 300).
- Смахивание: пока палец тянет, позиция ставится `anime.set(sheet, { y: dy })`
  и запоминается (`WeakMap sheetY`). Отпустили — шторка закрывается или
  возвращается **с этого места**. Закрывается, если сдвиг больше 25% высоты или
  жест быстрый (больше 40px и быстрее 0.6 px/мс).

### Тултип
`js/tooltip24.js`

- Появление: `opacity [0, 1]` + `y: [∓4, 0]` (придвигается к элементу), 200,
  `ease`. Затем ставится класс `is-visible` и вызывается `A24.clear`.
- Скрытие: `opacity: 0`, `y: ±4`, 200, в `onComplete` элемент удаляется.

### Тост сверху (профиль)
`js/profile24.js` → `showToast24()`

- `A24.reveal(toast, 'is-visible', true, { y: -80 }, { y: 0 }, 350, spring)`.
  Висит 1800 и уезжает обратно тем же `reveal(..., false, ...)`.
- По горизонтали тост центрирован CSS-свойством `translate: -50% 0`
  (см. раздел 13).

### Полёт иконки в цель
`A24.arc()`; `js/tasks22.js` → `TASKS22.flyIcon()`, `js/tasks.js` → `flyBolt()`, `burstAt()`

Используется для звёзд, снежинок и билетов.

`A24.arc(from, pop, ctrl, to, opts)` возвращает процентные ключевые кадры:
- `0%` — иконка в источнике (`scaleFrom`, `opacity 0`);
- к `popAt` — «выпрыгнула» в точку `pop` (`scalePop`, `rotate: spin`);
- дальше 12 шагов по квадратичной кривой Безье `pop → ctrl → to` с ускорением
  (`t²`), масштаб уменьшается до `scaleTo`, поворот гаснет.

Анимация идёт с `ease: 'linear'`: кривизна и ускорение уже заложены в кадры.

| | `flyIcon` (900) | `flyBolt` (820) |
|---|---|---|
| `popAt` | 0.22 | 0.24 |
| scale | 0.4 → 1.15 → 0.5 | 0.3 → 1.15 → 0.55 |
| `pop` | ±25px по x, на 20–40px выше | 16–38px в случайную сторону |
| `ctrl` | над серединой пути, на 60–120px выше | над серединой, на 40–120px выше, ±70px |
| поворот | — | ±30° |

- Несколько иконок летят с задержкой 65–90 между ними (`delay`).
- По прилёту каждой цель делает **пульс** (`A24.pulse`, 240–300), а в точке
  прилёта срабатывает **burstAt**:
  - кольцо `scale [0.3, 1.6]`, `opacity [1, 0]`, 380, `out`;
  - 6 искр, разлетаются на 20–34px (`x / y`, `scale [1, 0.2]`), 420, `outExpo`.

### Свернуть / развернуть карточку
`js/tasks.js` → `collapse()` / `expandIn()`

- Свернуть: `height [h, 0]`, `opacity [1, 0]`, `marginBottom [16, 0]`,
  `scale [1, 0.92]`, 320, `ios`; после этого элемент удаляется.
- Развернуть — обратно, 380, `ios` (через `A24.play`, стили потом убираются).

## 4. Задания

### Получение награды за задание
`js/tasks.js` → `claimTask()`

| Время | Что происходит |
|---|---|
| 0 | Если карточка не видна — плавная прокрутка к ней, ждём 420 |
| 0 | Плитка награды: `A24.squash(tile)` (360) |
| 0 | Звёзды (5–10 шт., по одной на 2 очка) летят в бирку шкалы — `flyBolt`, задержка `i × 65` |
| каждая звезда | Бирка: `A24.pulse(tag, 1.25, 240)` + `burstAt` |
| 0 | Снежинки (если есть): 4 шт. `flyIcon` в кнопку события, задержка `150 + i × 70`; кнопка — `A24.pulse(…, 1.18, 300)` |
| 260 | Карточка задания `collapse` (320), затем появляется в «Выполненных» — `expandIn` (380) |
| после всех звёзд | Шкала заполняется (см. ниже) |

### Заполнение шкалы
`fillProgress()`

Одна анимация anime.js по **числу очков**. В её `onUpdate` синхронно
обновляются ширина полоски, число в бирке и «зажигание» сундуков:

```js
const state = { pts: fromPoints };
anime.animate(state, { pts: toPoints, duration: 900, ease: 'out(3)', onUpdate: () => { … } });
```

- По полоске пробегает блик (`.tasks-fill-shine`): `left ['-60%', '110%']`,
  `opacity [1, 0]`, 900, `out`.
- Когда полоска доходит до сундука, он «просыпается»:
  `A24.pulse(chest, 1.35, 420, spring)`, переходит в состояние «готов» и
  запускает `animateReadyChest`.

### Сундук «готов»
`animateReadyChest()`

- Подпрыгивает, `A24.loop` на `.tchest-img`, цикл 1600, `inOut`. Кадры:
  `0–55%` — покой, `65%` — `y −6, rotate −6`, `75%` — `y 0, rotate 4`,
  `83%` — `y −2, rotate −2`, `100%` — покой.
- Золотое свечение за ним, `A24.loop` на `.tchest-glow`, цикл 3000, `inOut`:
  `rotate −8 → 0 → 8 → 0 → −8`, `scale 1 ↔ 1.06`, `opacity 1 ↔ 0.9`.
- `.tchest` центрирован свойством `translate: -50% 0` (anime пишет `transform`).
- Подсказка «Вам доступен приз» (показывается один раз) появляется через 450
  после входа в «Задания»: `A24.play(tip, { opacity: [0, 1], y: [-6, 0], scale: [0.92, 1], duration: 260, ease: spring })`.
  Скрывается так: `opacity [1, 0]`, 160.

### Плитка награды выполненного задания
`animateClaimableReward()`: `A24.loop`, `boxShadow` жёлтым
`0 0 8px rgba(255,221,45,.35) ↔ 0 0 18px rgba(255,221,45,.6)`, 800 туда и
800 обратно (`alternate`), `inOut`.

### Открытие сундука-вехи
`openChest()` → `playLootbox({ id: 'daily' | 'weekly', order }, rewards)`

Тот же экран, что в магазине (раздел 5), но **без** монет и ключа в начале и
**без** бонуса. После «Забрать» сундук на шкале меняется на открытый с
«попом»: `keyframes: [{ scale: [0.6, 1.15] }, { scale: 1 }]`, 420, `spring`.

### Кнопка события в углу «Заданий»
`js/events22.js` → `syncEventFab23()`, `renderEventFab23()`

- Появляется при входе в «Задания»: `scale 0.4 → 1.08 (70%) → 1` + `opacity`, 380, `out`.
- Нажатие: `A24.pulse(fab, 0.92, 200)`.
- Полоска прогресса доезжает: `width`, 700, `'cubicBezier(0.45, 0, 0.25, 1)'`.
- Бейдж-счётчик «впрыгивает»: `A24.popIn(badge, 1.5, 420, 300)`.
- Покачивание приза и пульс свечения кольца в 2.3 **выключены**: по макету
  это шестиугольник со статичным свечением.

## 5. Магазин

### Витрина и шторка сундука
`js/shop.js` → `levitate(el, phase)`

- Сундуки левитируют: `A24.loop(el, { y: [0, -8], rotate: [-1.5, 1.5], duration: 1600, alternate: true, ease: inOut })`.
  Полный цикл 3200. Фаза сдвинута на `i × 1100` (`anim.seek(phase)`), чтобы
  соседние сундуки не двигались синхронно. В шторке — то же самое.
- Шторка сундука — общая шторка (раздел 2). «Открыть» закрывает её и сразу
  запускает экран открытия.
- Баланс «досчитывает» до нового значения за 600 (`out(3)`), плашка —
  `A24.pulse(…, 1.12, 360)`.

### Экран открытия сундука
`js/shop.js` → `openLootbox()` → `playLootbox(box, rewards)`

Экран общий для магазина и сундуков заданий. Сундук стоит в блоке 540×540
(координаты сундука, прорези, скважины и «пасти» — `LB_XL`).

**Вся последовательность — один `anime.createTimeline()`.** Каждый шаг — функция
`(tl, t) → t_конца`, которая добавляет свои анимации в таймлайн с абсолютного
момента `t` (`tl.add(target, params, t)`, `tl.call(fn, t)`, `tl.set(target, props, t)`):

```js
const tl = anime.createTimeline();
let t = lbIntro(tl, 0);
if (box.insert === 'key') t = lbKey(tl, t, box);
else if (box.insert === 'coins') t = lbCoins(tl, t, box);
t = lbShake(tl, t);
t = lbOpen(tl, t);
t = lbFlyOut(tl, t, box, rewards, cells);
await tl;
```

Сетка наград рисуется сразу, но невидимой: пути вылета считаются от неё.

**Пропуск.** Крестик во время анимации вызывает `lbSkip = true; lbTimeline.complete()`.
Таймлайн мгновенно встаёт в конечное состояние (сетка наград, «Забрать»), а
эффекты из `tl.call` (блики, вспышки, конфетти, вибро) при `lbSkip` не
запускаются.

**Подсветка живёт всё время**, пока открыт экран (`startChestGlow`):
- большая 6-лучевая звезда `.lb-star-a`: `rotate [-12, 12]`, `scale [0.96, 1.12]`,
  `opacity [0.8, 1]`, 2500, `alternate`, `inOut` (полный цикл 5000);
- 15-лучевая `.lb-star-b` движется навстречу: `rotate [10, -14]`, `scale [1.06, 0.9]`,
  `opacity [1, 0.6]`, 1800, `alternate` (цикл 3600).

Это `A24.loop` на самих звёздах, а появление и разгорание идут на контейнере
`.lb-glow`, поэтому анимации не мешают друг другу.

**«Забрать».** Каждая награда остаётся на месте: поверх кладётся копия
(`liftReward`). Экран гаснет (`opacity [1, 0]`, 300, `in`). Награды улетают

## 13. Как переносить

- **Код переносится как есть.** Нужны anime.js v4 и `js/anim24.js` (или его
  функции внутри вашего проекта). В React вызовы удобно держать в `useEffect`
  или обработчике, с `ref` на элементы. Последовательности — через
  `await anime.animate(...)` (анимации thenable) или `createTimeline`.
- **Таймлайн с абсолютными позициями.** Сложные сцены (открытие сундука,
  «соперник найден», шторки, экран результата) собраны в `createTimeline` с
  явным временем каждого шага: `tl.add(el, params, 400)`. Колбэки — через
  `tl.call(fn, t)`, мгновенная смена — через `tl.set`. Пропуск сцены делается
  через `tl.complete()`.
- **Центрирование через `-50%`.** anime.js пишет свойство `transform` целиком.
  Поэтому у элементов, которые центрированы сдвигом на половину размера, этот
  сдвиг задан отдельным CSS-свойством `translate: -50% -50%` (или `-50% 0`):
  оно складывается с `transform` и не теряется. Так сделано у `.tchest`,
  `.e23-hex`, тоста профиля, конфетти, искр и чисел захвата.
- **Не используйте `anime.cleanInlineStyles`** для возврата элемента под
  управление CSS. Эта функция восстанавливает стили, которые были **до**
  анимации (например, стартовое `anime.set(opacity: 0)`), и элемент остаётся
  невидимым. Вместо неё — `A24.clear(el, params)` или `A24.play`, который
  вызывает `clear` сам.
- **Бесконечные анимации** — через `A24.loop`: он сам останавливается, когда
  элемент убран из DOM, и не запускается при «уменьшении движения». Если
  остановить цикл нужно раньше — `anim.cancel()` (оставить как есть) или
  `anim.revert()` (вернуть исходное состояние).
- **Синхронные вещи** (шкала + число + «зажигание» сундуков, набегание монет,
  счётчик снежинок, заливка захвата) — одна анимация anime.js по числу в
  объекте, а всё остальное обновляется в `onUpdate`.
- **Полёты «в цель»** считают координаты на лету (`getBoundingClientRect`),
  поэтому цель (счётчик, таб) должна быть на экране в момент старта.
- **Псевдоэлементы** anime.js не анимирует. Всё, что движется, — настоящие
  элементы (луч и ореол в поиске соперника, блик на шкале `.tasks-fill-shine`).
- **Что осталось в CSS** (не сюжетные анимации, а мгновенные отклики и смена
  состояния — так и задумано):
  - нажатия `:active`;
  - тумблеры;
  - смена цвета: кольцо таймера, свечение круга мечей при `is-found`;
  - подложка шапки при прокрутке (псевдоэлемент);
  - поворот стрелки в FAQ магазина;
  - эффекты оформления в `css/cosmetics24.css` — это «материал» рамок и
    рубашек, а не анимация интерфейса.
