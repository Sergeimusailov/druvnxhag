# Баланс карт — рабочие материалы

Черновой ростер из 72 карт и симулятор для проверки баланса. **В игру пока НЕ внедрено** —
это данные и инструменты для будущей интеграции в `js/cards.js`.

## Файлы
- `roster.js` — 72 карты: `{ name, rarity, arch, top, left, right, bottom }`.
- `sim.js` — симулятор баланса (жадный ИИ + учёт «безопасности» размещения). Запуск: `node balance/sim.js`.
- `positional.js` — позиционный анализ (сила карт по клеткам + форс-открытие). Запуск: `node balance/positional.js`.

Симуляторы — чистый локальный Node, без обращений к сети/ИИ.

## Дизайн ростера
Механика: числа 0–9 по 4 сторонам, захват если моя сторона строго больше соседней (как в матче).

**Редкости (доля в ростере):**
| Тир | Кол-во | Бюджет (сумма сторон) |
|-----|--------|-----------------------|
| Обычные | 44 (61%) | 9–15 |
| Редкие | 20 (28%) | 16–21 |
| Эпические | 8 (11%) | 20–24, экстремальная форма (большой пик + яма ≤2) |

**Архетипы (форма важнее суммы):**
- `uni` Универсал — ровные стороны. Центр, гибкость, защита.
- `ram` Таран — одна доминирующая сторона. Пробить конкретного соседа.
- `cor` Угловой — две соседние высокие (в поле), две низкие (в стену). Король своего угла.
- `lin` Линия — две противоположные высокие. Доминирует по оси.
- `bait` Приманка-0 — сторона 0 + высокие остальные. Риск/провокация.

Каждый архетип есть на каждом тире → любую стратегию можно собрать из карт разной редкости.
Принцип эпиков: самая экстремальная форма (пик 8–9 читается как редкость, яма ≤2 даёт контр-ручку),
а не «равномерно большие числа».

## Ключевые выводы симулятора
- **Миксы сбалансированы:** разброс среднего винрейта по архетипам ~2% (48.6–50.8%),
  лестница редкости плавная: обычные 47.6 → редкие 53.0 → эпики 56.0%.
- **Всеэпичная колода = ~87%** против случайного поля. Осознанно оставлено:
  решение — вариант B (не лимит колоды, а регулировать редкостью ДОБЫЧИ, дизайн добычи позже).
  Форма карт эту проблему не решает (пик эпика радикально выше потолка обычных).
- **Позиционно:** отдельной «клетки-автопобеды» для эпика нет. Углы сильны для всех карт
  (классика: в углу открыты 2 стороны) — это здоровая глубина, не баг.
- **Фора первого хода велика (~70%)**: первый игрок ставит 5 из 9 клеток → стартует «+1».
  Это правило матча, не карты. На будущее: рассмотреть розыгрыш первого хода монеткой.
